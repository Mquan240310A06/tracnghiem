Hướng dẫn đưa trang web lên GitHub miễn phí

Trang web này được thiết kế 100% Client-Side trong 1 file index.html duy nhất nên chạy cực kỳ mượt trên GitHub Pages:

  1. Lưu toàn bộ mã nguồn trang này thành file có tên index.html.
  2. Đăng nhập vào GitHub.com và bấm nút New Repository (Đặt tên tùy ý, ví dụ: trac-nghiem-ai, chọn Public).
  3. Bấm Add file → Upload files → Kéo thả file index.html vào rồi bấm Commit changes.
  4. Vào mục Settings (Cài đặt của Repo) → Chọn Pages ở thanh menu bên trái.
  5. Ở mục Branch, chọn main (hoặc master) rồi bấm Save.
  6. Đợi khoảng 1 phút, GitHub sẽ cấp cho bạn 1 đường link dạng https://ten-ban.github.io/trac-nghiem-ai/ để truy cập làm bài ở mọi nơi!
💡 Mẹo: Tất cả câu hỏi bạn nhập sẽ tự động lưu trong trình duyệt (localStorage). Bạn cũng có thể bấm nút "Xuất file .JSON" để lưu bộ đề vào chung repo GitHub của mình.

Các định dạng câu hỏi được tự động nhận diện

1. Câu hỏi Trắc nghiệm nhiều lựa chọn (A, B, C, D...)

Đánh dấu * trước đáp án đúng HOẶC ghi Đáp án: A ở cuối câu:

Câu 1: Chiến thắng Điện Biên Phủ diễn ra vào năm nào?
A. 1945
*B. 1954
C. 1968
D. 1975
Giải thích: Chiến dịch Điện Biên Phủ kết thúc thắng lợi ngày 7/5/1954.

2. Câu hỏi Đúng / Sai đơn lẻ

Chỉ cần thêm (Đúng) hoặc (Sai) ở cuối câu:

Câu 2: Nước sôi ở 100 độ C trong điều kiện áp suất tiêu chuẩn. (Đúng)
Câu 3: Mặt Trời quay xung quanh Trái Đất. (Sai)

3. Câu hỏi Đúng / Sai dạng chùm (4 mệnh đề a, b, c, d theo chuẩn thi mới)

Mỗi mệnh đề bắt đầu bằng a), b), c), d) kèm (Đúng) hoặc (Sai) ở cuối dòng (hoặc dấu * ở đầu dòng cho ý Đúng):

Câu 4: Khi nói về mạng Internet và Web:
a) HTML là ngôn ngữ đánh dấu siêu văn bản. (Đúng)
b) GitHub Pages thu phí duy trì hàng tháng đối với repo Public. (Sai)
*c) CSS dùng để trang trí giao diện cho trang web.
d) JavaScript chỉ chạy được trên máy chủ mà không chạy được trên trình duyệt. (Sai)
