  • Đặt dấu sao * trước đáp án đúng: Ví dụ *A. Hà Nội hoặc *Đúng

  • Nếu văn bản của bạn lộn xộn hoặc chỉ là bài giảng chưa có câu hỏi, hãy bấm nút "Dùng AI Gemini phân tích / Tạo câu hỏi"!

Hướng dẫn đưa trang web này lên GitHub miễn phí

Ứng dụng này được đóng gói hoàn chỉnh chỉ trong 1 file duy nhất (index.html) nên bạn có thể đưa lên GitHub Pages cực kỳ dễ dàng trong 1 phút:

  1. Bấm nút "Tải file HTML" ở thanh công cụ phía trên để lưu file index.html về máy tính hoặc điện thoại của bạn.
  2. Đăng nhập vào GitHub.com và tạo một Repository mới (Bấm dấu + góc phải trên chọn New repository, đặt tên tùy ý và chọn Public).
  3. Bấm vào dòng "uploading an existing file", kéo thả file index.html vừa tải vào rồi bấm nút xanh Commit changes.
  4. Vào mục Settings của Repository → chọn Pages ở menu bên trái → Ở mục Branch chọn main rồi bấm Save.
  5. Đợi khoảng 30 giây, GitHub sẽ cấp cho bạn một đường link web để bạn và bạn bè truy cập làm bài ở mọi nơi!
